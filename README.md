# Duckdowns 🦆

Carrera de patos de hule en 3D por un río, en el navegador (Three.js r128 + Web Audio, sin assets externos).

**Jugar:** abre `carrera.html` (o la versión en GitHub Pages).

## Cómo se juega
- **Cualquier tecla** empuja a tu pato: mientras más rápido teclees, más avanza (mantener una tecla apretada no cuenta).
- **Mouse** a izquierda/derecha para esquivar remolinos, ramas, sapos y nenúfares.
- Choca con otros patos y chillan como hule.
- Los 3 primeros se salvan y suben al podio. A los demás les cae un meteorito. ☄️

La dificultad se ajusta en el objeto `CFG` al inicio del script de `carrera.html`.

## Música (opcional, local)
El juego reproduce `musica.mp3` si existe junto a `carrera.html`. El audio **no se incluye en el repo** (`.gitignore`); cada jugador pone su propia copia.

Canción sugerida: **"We Are Charlie Kirk" — SPALEXMA** · [Escúchala en YouTube](https://youtu.be/ZUHpUXlsvbI). Todos los derechos pertenecen a sus autores.
